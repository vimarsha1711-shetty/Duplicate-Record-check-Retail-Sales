# Duplicate Record Check – Retail Sales Dataset

## Objective
To check the Retail Sales dataset for duplicate records and document the results.

## Dataset
Retail Sales Dataset

## Tool Used
Microsoft Excel

## Duplicate Check
The dataset was checked using the **Remove Duplicates** feature in Excel.

## Result
- Total records checked: 9027
- Duplicate records found: 0
- Duplicate records removed: 0

## Action Taken
No records were removed because no duplicate records were found.

## Deliverables
- Duplicate Report
- Cleaned Dataset

## Conclusion
No duplicate records were found in the dataset. The cleaned dataset is ready for further analysis.
